## 制作物：学習記録アプリ
# 概要
 Supabaseを活用し、ユーザーごとに学習内容と学習時間を記録・管理できる学習管理アプリを開発しました。<br>
 React・TypeScriptでコンポーネント設計を行い、学習時間の集計やグラフ表示、認証機能などを実装しています。

# Frontend
- TypeScript
- React
- HTML/CSS
- Tailwind CSS

# Database
- Supabase

# Tools
- Git / Github
- VScode

# 主な機能
- 学習内容の記録
- 学習時間の記録
- 棒グラフの生成
- 合計学習時間を算出
- ユーザー認証

# 工夫した点
- 学習データはuseMemoとMapを利用して効率的に集計し、グラフ表示や総学習時間の計算を最適化
- UX向上のために、入力後の自動フォーカス、エラーメッセージ表示、Ctrl+Zによる削除機能、矢印キーによる移動など、マウス操作の削減を図った。
- 認証情報を自前のDBに保存・管理するのではなく、Supabase Authを利用。セキュリティ面で安心
- API通信中の「連打による二重リクエスト」を防止するために、認証処理中はボタンを押せないように設計
